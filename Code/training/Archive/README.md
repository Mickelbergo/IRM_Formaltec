# Archive

This directory contains archived/outdated diffusion model implementations that have been superseded by newer versions.

## Archived Files

- **diffusion_original.py** - Original implementation (one-hot mask concatenation, basic U-Net)
- **diffusion_dummy.py** - Tutorial/example code using butterfly dataset (not wound-specific)

## Why Archived?

These files are kept for reference and historical purposes but are no longer actively maintained.

**Current implementations:**
- Use `diffusion_enhanced.py` for the most advanced features
- Use `diffusion_fast.py` for speed-optimized training
